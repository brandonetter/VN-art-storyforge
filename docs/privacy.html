Emotional Asset Studio

API keys and saved data

The app never saves your API key. Images and job progress are saved separately in your browser.

What happens to my key?

Your key stays in the input field and this tab's JavaScript memory. When you start generation, revise, or choose to load available models, it is sent directly to OpenAI or OpenRouter in an Authorization header. GitHub Pages hosts the app's static files and does not receive your key through the app.

The app does not write keys to IndexedDB, localStorage, sessionStorage, cookies, saved jobs, downloads, or logs. There is no server key, environment fallback, analytics, or third-party JavaScript.

Refreshing requires entering your key again. Clear keys forgets both providers' keys from the page. An already running generation or model-list request retains its in-memory copy until it finishes; clearing the fields does not cancel that operation.

What does the app save?

IndexedDB stores your uploaded character, canonical reference, generated sheets, cutouts, accepted revisions, pending revision previews, prepared Neutral-anchor templates, provider name, selected model, template set, quality, resolution, timestamps, and progress. It never stores credentials. Provider error messages are displayed for the current session and are excluded from saved history.

Custom prompt templates (not typed revision instructions) are stored in this site's localStorage until reset or site data is cleared. Typed revision instructions, queued requests, and hidden working canvases stay in this tab's memory and are never saved. Refresh forgets them. Generated candidates are saved for your review; the app never automatically repeats a revision request after reloading.

Jobs belong to this browser and site address. To remove them, clear this site's data in your browser settings. Download any images you want to keep first.

What leaves my browser?

Loading models sends your key to the selected provider's /models endpoint, but no images or prompts. For generation, the provider receives the key, image references, prompt, and generation options needed for the request, including your typed revision instructions and supporting images when revising. That provider's own data policies apply. Cropping, resizing, previewing, and creating ZIP downloads happen locally.

These statements describe this app's behavior. Your browser, extensions, device, network tools, and provider may handle data independently; the app cannot control them.
